# License notes

This repo currently houses two future-distinct products under one license:
Santolina (the app, `apps/web`) and Paradox UI (the design system,
`packages/tokens` and `packages/ui`). Paradox UI is intended to become a
separately-licensed open source package (MIT) once it's ready for external
use — see `docs/repo-strategy.md` for the full reasoning.

Until that split happens, the root `LICENSE` (all rights reserved) applies to
the entire repo, including the `packages/` directories.
